Handled failures end green and explain themselves in Compose_result. Anything that breaks outright goes to Scope_catch, is written twice, and ends the run red.

Nothing retries. Fabric calls keep the default retry for 408, 429 and 5xx. After that a failure stays until someone re-runs the flow or runs MIG_RebuildAllCapacityPolicies.
One run at a time. The five event flows run at concurrency degree 1, so a bulk change queues rather than collides.
The rebuild has no Catch. RebuildCapacityPolicyRules answers Outcome = Failed, ends Succeeded, and stamps Fabric's error on the row itself.
Nothing alerts anyone. A red run, a filled column and a Logging row are only seen by someone who goes and looks.
