Nothing in steps 1-8 changes anybody's access. The first irreversible moment is activation, during migration.
A wrong connection fails quietly. Signed in as the importer, the flows run - as that person, seeing only their capacities.
A blank variable is never safe. It silently builds a malformed URL, or stops a flow publishing. Set a Current Value on all seven.
After cutover delete three MIG_ flows; keep MIG_RebuildAllCapacityPolicies, switched off.
